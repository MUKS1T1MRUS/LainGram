# LainGram


Rus_version


LainGram — модифицированный Telegram-клиент для Android, объединяющий расширенные возможности NagramXF и дополнительные функции exteraless с собственными улучшениями и изменениями интерфейса.

### Возможности

- **Расширенный музыкальный плеер** — удобное управление воспроизведением, отображение обложек альбомов и интеграция музыкальных функций.
- **Система плагинов** — установка дополнительных модулей, анализ их содержимого и управление разрешениями.
- **Гибкая настройка интерфейса** — дополнительные параметры оформления и персонализации.
- **Папки чатов** — удобная навигация между категориями переписок с сохранением нижней панели NagramXF.
- **Дополнительные функции** — развитие возможностей клиента и внедрение собственных решений.

### Философия проекта

LainGram создаётся с упором на функциональность, гибкость и свободу персонализации. Проект объединяет проверенные решения существующих Open Source-клиентов и собственные разработки.

Это не попытка создать ещё одну копию Telegram, а стремление собрать клиент, в котором пользователь сам определяет, каким должен быть его мессенджер.

**LainGram — See you in the Wired.**

### Основа проекта

- NagramXF
- exteraless
- Telegram Android

Проект не является официальным продуктом Telegram.


Eng_version


LainGram is a modified Telegram client for Android, combining the extended capabilities of NagramXF with additional features from exteraless, alongside its own improvements and interface customizations.

### Features

- **Enhanced Music Player** — convenient playback controls, album artwork display, and integrated music features.
- **Plugin System** — installation of additional modules, plugin code analysis, and permission management.
- **Customizable Interface** — additional appearance settings and personalization options.
- **Chat Folders** — convenient navigation between chat categories while preserving NagramXF's bottom folder navigation.
- **Additional Features** — continuous expansion of the client's capabilities through new features and custom implementations.

### Project Philosophy

LainGram is built around functionality, flexibility, and freedom of customization. It combines proven solutions from existing open-source clients with original development and improvements.

The goal isn't to create yet another Telegram clone, but to build a client where users have greater control over their messaging experience.

**LainGram — See you in the Wired.**

### Project Base

- NagramXF
- exteraless
- Telegram Android

LainGram is an unofficial third-party Telegram client and is not affiliated with Telegram.
